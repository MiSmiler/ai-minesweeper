# Contiguous Board hit-testing

The frontend hit-tests pointer input by coordinates, not by DOM target: every pointer position on the Board maps to a Cell, with the decorative hairline between Cells split at its midpoint between the two adjacent Cells. Target-based hit-testing (`ev.target.closest(".cell")`) treated the 1.5px hairline gap — the Board container's background showing through as the hairline — as "off a Cell": crossing a hairline mid-drag cleared the Press Preview, which then never recovered (the pressing phase's pointer-move ignores moves once the preview is null), while the Chord Preview recovered because the armed phase re-derives its preview unconditionally. The fix treats the Board as contiguous Cells — the hairline is purely visual.

Alternatives rejected: making the gap zero in CSS and drawing the hairline per-Cell (conflicts with the Hidden Cell's bevel borders and shrinks content under `box-sizing: border-box`); a whole-gap ownership rule (chose the midpoint split — it matches the "Cells touch" mental model at the same cost). The geometry (Cell size, hairline, pitch) is measured from the rendered Cell rects — the span between the first and last Cell of the first row/column — never from CSS constants or computed styles, so CSS changes and subpixel rendering cannot drift the mapping; the Board's origin is read fresh per event since layout can shift.

Consequences: right-click on a hairline Flags the Cell owning it (previously no Flag); release on a hairline Reveals/Chords the owning Cell (previously nothing); the midpoint split keeps the mapping continuous — no position inside the Board is "no Cell". ADR-0005's "leaving the Board cancels the press" boundary is the Board's outer edge, unchanged — and, unified with the Press Preview, the Chord Preview is now also terminal on a leave: once the pointer has left the Board, re-entering does not restore it until the gesture re-arms. The machine's off-Cell paths remain reachable only through the test seam (ADR-0007); the pure offset→index math lives in a tested module (`hitTest.ts`), keeping the bootstrap a thin adapter.
